Data Filtering

Remove variables that are unlikely to help downstream modeling.

  • Low-quality: features with too many missing values.
  • Low-repeatability: features with high percent RSD based on QC replicates.
  • Low-variance: features that are near-constant across conditions.
  • Low-abundance: features with very small values (close to baseline).
