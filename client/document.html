Technical Documentation

IS/NIST preprocessing

Optional preprocessing mode requiring a raw matrix, NIST reference samples, and an IS mapping file. Pure pandas logic.

1. IS — compound/IS ratios

Each compound divided by its assigned internal standard. Applied to study and NIST samples alike:

$$ \hat{x}_{ij} = \frac{x_{ij}}{s_{\text{istd}(i),\,j}} $$

2. NIST — ratio of ratios

Each study sample maps to a NIST sample. Each compound's ratio divided by the same compound's ratio in the mapped NIST:

$$ \tilde{x}_{ij} = \frac{\hat{x}_{ij}}{\hat{x}_{i,\,\text{nist}(j)}} $$

NIST samples removed after correction.

Data filtering

Libraries: pandas, numpy. Four sequential filters, each skippable by setting its threshold to 0.

A. Missing-value filter

$$ \text{mv}_i = \frac{\#\text{NaN in feature } i}{\#\text{samples}}, \qquad \text{keep } i \iff \text{mv}_i \le \frac{\text{mv\_threshold}}{100} $$

B. RSD filter (QC samples)

QC samples auto-detected by column-name match (substring "rsd"); requires ≥ 3, else skipped.

$$ \text{RSD}_i = \frac{\operatorname{std}(\text{QC}_i)}{\operatorname{mean}(\text{QC}_i)}, \qquad \text{keep } i \iff \text{RSD}_i \le \frac{\text{rsd\_threshold}}{100} $$

C. Low-variance filter

$$ \text{IQR:}\ v_i = Q3_i - Q1_i \qquad \text{SD:}\ v_i = \sigma_i \qquad \text{MAD:}\ v_i = \operatorname{median}\!\bigl(|x_{ij}-\operatorname{median}(x_i)|\bigr) $$
$$ \text{thresh} = \operatorname{quantile}(v,\ \text{var\_percent}/100), \qquad \text{keep } v_i > \text{thresh} $$

D. Low-abundance filter

$$ \text{score}_i = \operatorname{mean}(x_i) \text{ or } \operatorname{median}(x_i), \qquad \text{keep } \text{score}_i > \operatorname{quantile}(\text{score},\ \text{abun\_percent}/100) $$

Normalization

Libraries: scipy.stats, sklearn.preprocessing.QuantileTransformer, pycombat.

1. Sample normalization (column-wise)

  • None — no scaling.
  • Median/Total — each sample divided by its median or sum.
$$ \hat{x}_{ij} = \frac{x_{ij}}{c_j}, \qquad c_j = \operatorname{median}(x_{\cdot j}) \text{ or } \sum_i x_{ij} $$

2. Data transformation

none, log2, log10, sqrt applied element-wise. Zeros handled before transform (step 5).

3. Batch correction

None or ComBat via pycombat — empirical-Bayes adjustment of feature means/variances across batches defined by a metadata column.

4. Scaling (feature-wise)

$$ \text{mean-center:}\ \hat{x}_{ij} = x_{ij} - \mu_i \qquad \text{Pareto:}\ \hat{x}_{ij} = \frac{x_{ij}-\mu_i}{\sqrt{\sigma_i}} \qquad \text{auto (Z):}\ \hat{x}_{ij} = \frac{x_{ij}-\mu_i}{\sigma_i} \qquad \text{range:}\ \hat{x}_{ij} = \frac{x_{ij}-\min_i}{\max_i - \min_i} $$

Quantile normalization (optional) uses sklearn QuantileTransformer to map feature distributions to a normal output.

5. Zero/missing handling

  • None — leave as-is.
  • 1/5 minimum — replace zeros with one-fifth of the feature minimum (left-censored approximation).
  • QRILC — Quantile Regression Imputation of Left-Censored data; zeros treated as left-censored values below the detection limit and imputed via quantile regression.

Analysis modules

Summary of the analysis modules, their method/library and key output.

ModuleMethod/LibraryKey output
PLS-DA/OPLS-DA/VIP sklearn PLSRegression, pyopls.OPLS, scipy.stats S-plot: \(p_i=\text{cov}(x_i,t_{\text{pred}})\), \(p_{\text{corr}}=\rho(x_i,t_{\text{pred}})\) (Spearman/Pearson). VIP: \(\text{VIP}_j=\sqrt{p\cdot\frac{\sum_a w_{ja}^2\,\text{SSY}_a}{\sum_a\text{SSY}_a}}\). Permutation + CV-ANOVA validation. Combined table merges VIP with LogFC + FDR.
PCA/UMAP/t-SNE sklearn.decomposition.PCA, umap-learn, sklearn.manifold.TSNE Scores, loadings, explained variance ratios. Group order follows the saved metadata ranking.
T-test & ANOVA scipy.stats (ttest, mannwhitneyu, wilcoxon, shapiro, f_oneway, kruskal), statsmodels, scikit_posthocs, pingouin Auto mode picks Student/Welch or Mann-Whitney/Wilcoxon (T-test) and ANOVA or Kruskal-Wallis by normality and variance. FDR via Benjamini-Hochberg.
Biomarker statsmodels.OLS, scipy.stats (pearsonr/spearmanr), sklearn.metrics (roc_curve, auc), StratifiedKFold OLS regression \(\beta\), \(p\), FDR, \(R^2\); correlation; ROC AUC with bootstrap CI and Youden's \(J = \text{sensitivity} + \text{specificity} - 1\) cut-off.
Enrichment gseapy (GSEA/ORA), networkx GSEA: ES/NES/FDR on a ranked list. ORA: hypergeometric test. Dot plot (size = % Feature, color = \(-\log_{10}\text{FDR}\)) and gene-set network.
Clustering & HCA sklearn.cluster.KMeans, minisom.MiniSom, scipy.spatial.distance.pdist, plotly.figure_factory K-means on PCA scores (labels saveable as metadata); SOM grid + BMU assignment; HCA dendrogram + clustered heatmap.
Classification sklearn.ensemble.RandomForestClassifier, sklearn.svm.SVC, sklearn.inspection.permutation_importance Confusion matrix, precision/recall/F1, feature importance (RF) / permutation importance (SVM), ROC AUC via stratified CV.
